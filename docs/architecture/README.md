# Architecture

This directory describes system boundaries, components, integrations, and data flows. It currently contains a documented product direction, not an implemented system.

## Documents

- [`system-overview.md`](system-overview.md) — current proposed boundaries and unresolved choices.
- [`data-flows.md`](data-flows.md) — proposed chat, reward, affiliate, and payment flows.
- [`component-template.md`](component-template.md) — template for adding a component without implying implementation.

## Update rules

Describe what is known, proposed, accepted, and implemented separately. Link every accepted architectural choice to an ADR in [`../decisions/`](../decisions/). Update data flows when API, database, identity, model-provider, advertising, or settlement behavior changes.
