# Architecture Decision Records

ADRs capture decisions that affect architecture, security, data, APIs, operations, or team workflow. Use [`ADR-template.md`](ADR-template.md). One ADR covers one decision.

## Status rules

- **Proposed:** under discussion; not a basis for implementation unless explicitly authorized.
- **Accepted:** approved direction; implementation may still be absent.
- **Implemented:** accepted and evidenced in code/tests.
- **Superseded:** replaced; link the replacement.

## ADR index

- [`ADR-0001-rks-operating-model.md`](ADR-0001-rks-operating-model.md) — Accepted: repository RKS as project continuity mechanism.

Product, technology, vendor, accounting, and security decisions remain unselected until an approved ADR records them.
