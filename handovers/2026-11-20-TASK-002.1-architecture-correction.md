## Key correction

The previous documents mixed positive business quantities with signed ledger entries. The corrected convention uses signed `amount_units`; reservation is `-R`, debit is `-A`, release is `+(R-A)`, and the net effect is exactly `-A`. Settlement returns only the unused hold to the projection; it does not subtract actual usage a second time. Pending reconciliation retains the full hold. Account-then-request locking is required across all accounting paths.
